The components section is a directory where the reusable UI components reside. Houses Vue 3 single-file components (SFCs)

# Components

1. **Common** (/common) : Generic UI elements reside here. Example : Buttons, inputs

2. **Layout** (/layout) : Structural components defining the positioning of components in the web page.

3. **Servers** (/servers) : These components are wired using the common elements with the game server data
