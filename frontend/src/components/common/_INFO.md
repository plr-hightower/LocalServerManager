# Common Subsection

Reusable UI elements 

## Files

1. 'AppButton.vue' : Buttons with outlines

2. 'AppInput.vue' : Styled text/number inputs with built-in validation styling

3. 'StatusBadge.vue' : UI element that shows Status of server (starting, online, offline)

4. 'BaseModal.vue' : Reusable popup wrapper (delete confirmation, etc.)

5. 'AppToggle.vue' : UI switch to toggle elements on/off (ex. pvp on/off)
