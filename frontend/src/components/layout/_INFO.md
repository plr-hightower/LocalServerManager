# Layout subsection

Manages the state of the screen for the user. Logic to guide user through the app.

## Files

1. 'SideBar.vue' : Main navigation (Dashboard, Game Lib, Settings)

2. 'TopBar.vue' : Shows current user, rig health, etc.

3. 'PageHeader.vue' : Standardized title section

4. 'AppLayout.vue' : Script that will link everything together
