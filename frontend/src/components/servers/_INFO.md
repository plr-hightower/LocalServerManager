# Servers Subsection

Where UI meets logic. Components are designed to interact with types too.

1. 'ServerCard.vue' : Card that shows the server name, status, etc.

2. 'ServerList.vue' : Container that loops though the instances and displays the cards inside.

3. 'ServerConsole.vue' : Area for real-time log output

4. 'ServerControls.vue' : Status button group with loading states.

5. 'ConfigForm.vue' : Dynamic form that renders inputs based on the schematic of the selected game.

6. 'MetricChart.vue' : Displays CPU/RAM of the rig upon usage of server instance.
