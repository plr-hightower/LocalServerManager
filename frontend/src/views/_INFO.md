# Views

Vue files are used to display to the web the information computed in the app.

## Files

1. 'Dashboard.vue' : Displays the main dashboard, presenting tables and UI

2. 'GameLibrary.vue' : Displays the interactable game library where the user will be able to choose from any game inside.

3. 'ServerDetails.vue' : Displays information about server of each game

4. 'Settings.vue' : Global rig settings (directories, api keys, etc.)
