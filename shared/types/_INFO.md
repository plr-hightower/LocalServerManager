# Shared Files

In this directory, the typescript files are shared accross the project with the implementation used in the files : package.json (each repository has one in it - see the code inside) and the index.ts file to point to the files

## Files

1. 'schematic.ts' : Defines the structure of the game blueprint (fields, inputs, etc.)

2. 'server.ts' : Defines the state of an active server instance (ID, Status, IP, Port, Stats, etc.)

3. 'api.ts' : Defines Request/Response shapes for the backend (api is calling)
